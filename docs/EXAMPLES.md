# content/examples

Runnable artifacts with the reasoning written round them. Each is either a
single `.md` with a complete, copy-pasteable artifact inside it, or a directory
with the article at `index.md` and the artifact in files beside it.

The bar: a reader clones it and it works. No elisions, no
`# ... rest of implementation`. Every example states how it fails and what it
cost to build, because those two sections are why the rest of it is believed.
